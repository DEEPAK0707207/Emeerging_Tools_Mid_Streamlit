# IMDb Movie Dashboard 🎬

An interactive dashboard to explore and analyze IMDb Top 250 movies using Python and Streamlit.

## Features
- Explore IMDb Top 250 movies.
- Analyze movie ratings and votes.
- Visualize movie genres.
- Search movies by title.
- Filter movies by genre, country, and rating.
- View interactive charts and statistics.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Installation

```bash
pip install streamlit pandas numpy plotly
```

## Run the Project

```bash
streamlit run app.py
```

## Dataset
IMDb Top 250 Movies dataset (CSV).
